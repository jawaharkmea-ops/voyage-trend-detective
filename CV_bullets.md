**NASA Space Apps Challenge 2026: Voyage Trend Detective** (Solo participant, Nov 2026)
- Built a Python pipeline using NASA POWER data to detect long-term trends and anomalies in sea-state conditions on three shipping routes.
- Developed an interactive dashboard with route-risk forecasting and a simulated engine-room/switchboard health monitor with threshold alerts.
- Published open-source code and documentation on GitHub (https://github.com/jawaharkmea-ops/voyage-trend-detective) with a live demo dashboard (https://jawaharkmea-ops.github.io/voyage-trend-detective/dashboard/).
